跟着做

先到 TRAE 国内版官方下载页，选择桌面端 Windows (x64)。装好后新建一个练习文件夹，用 TRAE 打开，再把下面这段话发给右侧的 AI。生成后保留并保存，回到文件夹双击 index.html。

请在当前文件夹创建一个 index.html，做一张课堂欢迎卡。大标题写“欢迎来到我的课堂”，下面写“今天，从一个好问题开始”。用浅色背景、深色大字，居中即可。只用一个文件，不安装软件、不运行命令。
