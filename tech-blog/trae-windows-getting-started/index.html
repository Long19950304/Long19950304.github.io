Follow along

Open the official TRAE download page and choose Windows (x64). After installing, create a practice folder and open it in TRAE. Send the prompt below in the AI chat, keep and save the result, then double-click index.html in File Explorer.

Create an index.html file in this folder for a classroom welcome card. Use “Welcome to my classroom” as the heading and “Today, let’s start with a good question” below. Use large, dark text on a light background. Keep everything in one file. Do not install software or run commands.
